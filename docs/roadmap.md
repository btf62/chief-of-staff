# Roadmap

- **Status:** Draft
- **Owner:** TBD
- **Last updated:** 2026-07-25

Dates and estimates are intentionally omitted until scope and ownership are
clear.

## Phase 0: Discovery

- Define the problem and intended users.
- Gather evidence for priority user needs.
- Agree on outcomes, constraints, and non-goals.

**Exit criteria:** Product vision is accepted and initial requirements are
reviewable.

## Phase 1: Design

- Define user workflows and measurable acceptance criteria.
- Document data, privacy, security, and integration constraints.
- Propose the system context and high-level architecture.
- Record consequential choices as ADRs.

**Exit criteria:** Requirements and architecture are accepted, with major risks
owned.

## Phase 2: Implementation planning

- Break the first validated capability into small deliverables.
- Select tooling and development practices through documented decisions.
- Define validation, release, rollback, and operational readiness criteria.

**Exit criteria:** The first implementation milestone is approved and ready to
build.

## Phase 3: Implementation

Out of scope for repository initialization. This phase requires explicit
authorization after the preceding exit criteria are met.
