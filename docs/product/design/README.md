# Product Design Handoffs

This directory contains reviewable interface and information-design handoffs.
They translate accepted product behavior into proposed presentation systems
without silently changing feature scope, source authority, agency, privacy, or
roadmap authorization.

A design handoff does not authorize implementation by itself. Its status must
be read together with the accepted feature specifications, architecture
decisions, and implementation roadmap.

Committed reference images live under [`assets/`](assets/). They use only
synthetic content and illustrate the reviewed visual direction; the written
product and design contracts remain authoritative.
