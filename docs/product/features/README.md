# Feature Specifications

This directory is the authoritative location for detailed, implementable
feature specifications. Each specification should define behavior, inputs,
outputs, constraints, acceptance criteria, dependencies, and unresolved
questions without duplicating the top-level PRD or governing foundations.

Use [`../../../templates/feature-spec.md`](../../../templates/feature-spec.md)
when creating a specification.
